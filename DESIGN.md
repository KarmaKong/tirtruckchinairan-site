# Documents & Seals

## 1. Visual theme
An international transit file: paper, thin rules, recorded handoffs. The Bukhara transload is the distinctive orange break in the seal-status line.

## 2. Palette
Paper #F6F3EC; ink #0B2545; seal orange #C2410C; secondary text #646B75. Orange is reserved for the primary enquiry button and transload marker. The darker approved orange supports normal-size white button text at AA contrast.

## 3. Typography
Persian: Vazirmatn variable. English: IBM Plex Sans variable. Chinese: Source Han Sans SC regular. Figures: IBM Plex Mono regular. WOFF2 subsets, self-hosted, font-display:swap. Chinese extra glyphs use a second unicode-range subset. Persian body line-height 1.9; headings 1.48. No remote font requests.

## 4. Components
Square buttons, native details/summary FAQs, real HTML tables with captions and row/column headers. No forms, analytics, cookies, client-side script, or UI frameworks. JSON-LD scripts contain data only.

## 5. Layout
Max-width 1280px including 40px inline padding; mobile 20px padding. Large unboxed sections; three carnet-like stubs with perforation rules. The Persian desktop hero places the seal image on the right.

## 6. Depth
No decorative shadows, gradient surfaces or floating cards. Separators and whitespace create hierarchy.

## 7. Rules
Never depict the official TIR plate as this brand's logo. Never imply zero inspections, zero transloads, a guaranteed arrival, DDP or door-to-door scope. Route graphics describe a plan, not live tracking. The generated seal image is labelled as an illustration.

## 8. Responsive behaviour
At 760px, the route becomes vertical, carnet stubs and quote checklist stack, and the hero is a single column. Navigation wraps. Focus remains visible. Reduced-motion users receive no press transform. The primary CTA remains in the mobile hero; the duplicate header CTA is hidden on mobile.

## 9. Future editing guide
Keep paper #F6F3EC, ink #0B2545, orange #C2410C, square corners, and one shared logical-property CSS stylesheet. Add content in static HTML. New Chinese glyphs require regenerating the subset; system sans-serif is the fallback. Replace the illustrative seal photograph with an authorised operational photograph in the same AVIF/WebP sizes, update its alt/caption, and preserve width/height.
